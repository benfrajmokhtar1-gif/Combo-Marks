# Combo Marks — Fabric 1.20.1

هذا مشروع مصدر لمود Minecraft Java Edition يعمل مع Fabric 1.20.1 وFabric API.

## ماذا يفعل؟
- يحسب ضربات اللاعب المتتالية ضد نفس الوحش المعادي خلال 3 ثوانٍ.
- عند الضربة الثالثة، يضيف تأثير دفع بسيط وجزيئات.
- عند الضربة الخامسة، ينشئ تأثير انفجار بصري ويدفع الوحوش المعادية القريبة.
- يعيد العدّاد بعد 3 ثوانٍ من دون ضرب الهدف.

## بناء ملف JAR مجانًا عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub باسم `combo-marks`.
2. ارفع جميع ملفات هذا المشروع مع الحفاظ على المجلدات.
3. افتح تبويب **Actions** في المستودع وفعّل Actions إذا طُلب منك.
4. شغّل **Build Combo Marks** عبر زر **Run workflow**، أو انتظر تشغيل البناء بعد رفع الملفات إلى فرع `main`.
5. افتح نتيجة التشغيل الناجحة، ثم نزّل ملف **combo-marks-jar** من قسم **Artifacts**.
6. فك ضغط ملف Artifact، ثم ضع ملف `.jar` الناتج في مجلد `mods` مع Fabric API.
